# Product

<!-- impeccable:product-schema 1 -->

## Platform

web (Next.js, Pages Router)

## Stack

Next.js, React, Tailwind CSS, Lucide icons

## Users

Primary: **Technical recruiters and hiring managers** scanning developer portfolios for frontend/fullstack candidates. Secondary: **Potential freelance clients** evaluating capability and fit.

## Product Purpose

Portfolio website that establishes Marzuki as a credible, capable frontend engineer and fullstack developer. Serves as the definitive reference for skills, projects, and professional identity. Must earn trust fast — visitors form an impression in seconds.

## Positioning

Indonesian developer specializing in modern web stack (React, Next.js, TypeScript, Tailwind). Not a generic portfolio — the aesthetic communicates technical taste and attention to detail. Clean, fast, intentional.

## Operating Context

- Visitors arrive via Google, direct link, or LinkedIn
- Primary pages: homepage (search-style entry), about (full bio), projects portfolio
- Contact via email, LinkedIn, or GitHub
- Resume available as PDF download
- Mobile-first traffic

## Capabilities and Constraints

- Static content from JSON files (portfolio.json, techstack.json)
- Admin dashboard for managing projects and tech stack
- No e-commerce, no user accounts, no backend API
- Image assets stored locally in `/public/img/`
- PDF resume served statically

## Brand Commitments

- **Name**: "Ukay" as personal brand, `ukay.dev` as domain
- **Visual identity**: Colorful "Google-colored" brand letters (U=red, k=red, a=yellow, y=blue, .=gray, d=green, e=red, v=blue)
- **Aesthetic inheritance**: Current v2 uses Google Search visual metaphor — not a requirement, a starting point

## Evidence on Hand

- 15+ real projects with live links (Dokumin.web.id, Agent Loker, etc.)
- 10 confirmed tech stack items (HTML, CSS, JS, Node, React, Next.js, Tailwind, PHP, MySQL, Git)
- Real social links: GitHub (marzukiberg), LinkedIn
- Real profile photo at `/public/img/profile.jpeg`
- Real PDF resume at `/Marzuki_Front-End_Developer_Resume_ATS.pdf`

## Product Principles

1. **Clarity over cleverness** — visitors are evaluating competence, not decoding creativity
2. **Proof over claims** — projects with live links, real descriptions, actual tech used
3. **Performance is design** — fast load times signal professionalism
4. **Mobile parity** — full experience on any device, no "best viewed on desktop"
5. **Maintainable by one person** — JSON-driven content, minimal dependencies

## Accessibility & Inclusion

Standard web accessibility: semantic HTML, alt text for images, keyboard navigation, sufficient color contrast. No specific a11y requirements established beyond baseline.
